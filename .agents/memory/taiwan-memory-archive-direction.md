---
name: Taiwan memory archive product direction
description: Durable product direction for changes to the Taiwan Play Memories archive.
---

Keep the Google Sheets-driven public site as the visual and content base when integrating community features. Story browsing, likes, favorites, and submissions can use the shared API without replacing that page.

The user wants pending submissions to appear publicly with a clear review badge. Voice features, a decade timeline, a Taiwan memory map, and collectible badges are later roadmap ideas rather than MVP requirements unless requested again.

**Why:** The user selected the remote Google Sheets version to remain the base and explicitly separated launch essentials from future enhancements.

**How to apply:** Extend the existing Taiwan archive artifact rather than replacing it with the older editor app. Keep deferred roadmap ideas out of the MVP merge unless the user reprioritizes them.
